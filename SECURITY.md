# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.8.x   | Yes       |
| < 1.8   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in FinTrack, please report it privately instead of opening a public issue:

1. Use GitHub's **Report a vulnerability** button under the repository's **Security -> Advisories** tab, or contact the maintainer directly.
2. Include a clear description of the issue, reproduction steps, and affected components or files.
3. Allow reasonable time for triage and a fix before any public disclosure.
